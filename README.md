# 🛡️ CyberBERT: Hybrid Transformer-Based Phishing URL Detection for Zero-Day Threats

## Introduction

CyberBERT is a hybrid transformer-based phishing URL detection framework designed to identify malicious and legitimate URLs with high accuracy. The model combines the contextual understanding of **BERT (Bidirectional Encoder Representations from Transformers)** with handcrafted lexical and structural URL features, enabling it to detect sophisticated phishing attacks, including zero-day threats and obfuscated URLs.

Unlike conventional phishing detection methods that rely solely on manually engineered features or blacklist-based approaches, CyberBERT leverages deep contextual embeddings alongside cybersecurity-specific feature engineering to improve robustness and generalization. By integrating semantic understanding with domain-specific URL characteristics, the proposed framework effectively captures both contextual and structural indicators of phishing attacks.

The proposed hybrid architecture performed well , outperforming traditional machine learning models as well as standalone BERT, making it a promising solution for real-world cybersecurity applications such as browser security, email filtering, enterprise threat detection, and financial fraud prevention.
